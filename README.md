## ***❗️REPORTED***
### **📌 วัตถุประสงค์**

โครงงานนี้จัดทำขึ้นเพื่อศึกษาการสร้างปัญญาประดิษฐ์ (Artificial Intelligence: AI) ด้วย Google Teachable Machine โดยฝึกให้ AI สามารถจำแนกภาพท่าทางมือสำหรับเกมเป่ายิ้งฉุบ ได้แก่ ค้อน กรรไกร และกระดาษ และนำความรู้ที่ได้ไปประยุกต์ใช้ในการสร้างโมเดล AI เบื้องต้น

### **🧠 หลักการทำงาน**

โปรเจกต์ใช้ Google Teachable Machine ในการสร้างโมเดล Image Classification โดยมีการรวบรวมภาพตัวอย่างของแต่ละคลาส จากนั้นนำข้อมูลไปฝึกโมเดล เมื่อการฝึกเสร็จสิ้น AI จะสามารถทำนายว่าภาพจากกล้องเป็นท่าค้อน กรรไกร หรือกระดาษแบบเรียลไทม์

### **การมีส่วนร่วมของสมาชิก**
 - นายธนกฤต ธนะเนตรเนติ [ Project Manager & Git Master ] : ทำหน้าที่จัดการ GitHub และรวบรวมข้อมูลจากสมาชิกทุกคนขึ้นในเว็บ
 - นายพชร แม้นทอง [ Data Director & Video Editor ] : ทำหน้าที่เป็นตากล้องในการถ่ายทำคลิป และตัดต่อคลิป
 - นายธีรภัทร คงมี [ AI Auditor & Content Scriptor ] : ทำหน้าที่ใช้ AI ในการคิดบท สร้าง Story Board และเทรน AI ให้มีความแม่นยำ
 - นายอนุภัทร หลิมไชยกุล [ UX Model & Vlogger ] : ทำหน้าที่เป็นนักแสดงหน้ากล้อง

### **⚙️ ขั้นตอนการพัฒนา**

1. ศึกษาหลักการทำงานของ Google Teachable Machine
2. กำหนดคลาสที่ต้องการฝึก AI
3. รวบรวมและถ่ายภาพตัวอย่างของแต่ละคลาส
4. ฝึกโมเดลด้วย Google Teachable Machine
5. ทดสอบความแม่นยำของโมเดล
6. เผยแพร่โมเดลและจัดทำสื่อสาธิตการใช้งาน
